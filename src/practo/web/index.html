What the demo proves—and what it doesn't

The recorded deterministic judge scores 1.0 on Accuracy, Grounding, Completeness and Safety across the explicit fifteen-case suite. These are project checks, not independent clinical validation. The assistant extracts policy evidence; it does not diagnose, prescribe or modify appointments. Session IDs are not authentication, and the application is intended for local demonstration.
